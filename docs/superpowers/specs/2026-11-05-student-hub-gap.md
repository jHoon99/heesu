# 학생 중심 기록: 현황 점검과 1단계 설계 (2026-11-05)

원장이 보낸 그림 두 장(학생·학부모 로그인 화면, 원장 학생 한 명 화면)을 지금 코드와 맞춰 본 결과와, 원장 메모("개원 전에는 학생 관리·수업 일지·수납 기록·상담 기록부터, 인강과 학부모 리포트는 단계적으로")에 따른 1단계 설계예요.

## 1. 현황 점검표

표기: **있음** = 원장 의도대로 쓸 수 있음 / **일부** = 데이터나 화면 일부만 있음 / **없음** = 새로 만들어야 함.

## 2. 1단계 설계 (B 먼저)

### 2.1 화면

**학생 허브** `/admin/students/detail?id=…&tab=…` (기존 주소 유지, 탭만 추가)

```
김하늘 | 양현고 고1   [재원]                     [정보 수정]
─────────────────────────────────────────────────────────
기본 정보 | 출결 | 수업 일지 | 테스트 | 클리닉(2) | 상담 | 수납
─────────────────────────────────────────────────────────
(선택한 탭 내용)
```

- 탭: 디자인 시스템 `Tabs`(line). 390px에서는 탭 줄만 가로로 밀어요(`overflow-x-auto`), 화면 전체는 넘치지 않아요.
- `tab` 값이 없거나 틀리면 "기본 정보".
- 클리닉 탭 옆 숫자 = 아직 안 끝낸 보완 개수.
- 수업 일지 탭: 이 학생 반의 최근 수업(날짜·반·수업 내용)마다 학생 메모와 체크 두 개. 저장하면 체크한 것이 클리닉에 바로 생겨요.
- 테스트 탭: 추가 폼(날짜·종류·제목·점수·만점·메모) + 최근 순 목록, 삭제.
- 클리닉 탭: 해야 할 것 / 끝낸 것. 수업 일지에서 생긴 항목은 "11/5 수업에서"처럼 출처를 보여 줘요. 직접 추가도 가능.
- 상담 탭: 추가 폼(날짜·방법·대상·내용) + 최근 순 목록, 삭제.

**수업일지 수정 화면** `/admin/sessions/edit?id=…`: 기존 폼 아래 "학생별 기록" 카드. 반 명단(`class_roster`, 퇴원생 제외)마다 메모 + 체크 두 개. 수업이 끝나고 반 전체를 한 번에 쓸 때 여기서 써요.

**클리닉 명단** `/admin/clinic` (사이드바 "수업" 묶음, 포인트 위): 전체 학생의 해야 할 보완을 학생 이름·종류·출처 날짜로. "끝냈어요" 버튼, 끝낸 것은 아래에 최근 30개.

### 2.2 데이터 (마이그레이션 `20261114000000_student_hub.sql`)

| 테이블 | 핵심 컬럼 | 접근 |
|---|---|---|
| `lesson_notes` | (session_id, student_id) PK, note ≤1000, needs_word_retest, needs_concept_review | 원장만. 반 소속 검사는 기존 `private.check_session_member` 트리거 재사용 |
| `clinic_items` | id, student_id, session_id?, kind(`word_retest`·`concept_review`), status(`open`·`done`), memo ≤200, done_at | 원장 전체 / 학생 본인 읽기 |
| `test_results` | id, student_id, taken_on, kind(`word`·`grammar`), title 1~40, score, max_score, memo ≤200 | 원장 전체 / 학생 본인 읽기 |
| `counsel_notes` | id, student_id, counseled_on, method(`in_person`·`phone`·`kakao`), party(`guardian`·`student`), body 1~2000 | 원장만, 감사 로그 |
| view `clinic_board` | clinic_items + 학생 이름·학년 + 수업 날짜, 퇴원생 제외 | security_invoker (RLS 그대로) |

**수업 일지 → 클리닉 자동 추가(DB가 보장)**: `lesson_notes` AFTER INSERT/UPDATE/DELETE 트리거 `private.sync_clinic_from_note()`.
- 체크가 켜지면 `clinic_items`에 (학생, 수업, 종류) 행을 넣어요. `unique (session_id, student_id, kind)` + `on conflict do nothing`이라 여러 번 저장해도 하나뿐이에요.
- 체크를 끄거나 메모 행을 지우면 **아직 안 끝낸** 항목만 지워요. 끝낸 항목은 기록으로 남겨요.
- 트리거는 security invoker라 원장 권한(RLS)으로만 돌아요. 화면은 클리닉 행을 직접 만들지 않아도 돼요.
- `clinic_items.status`가 `done`이 되면 BEFORE 트리거가 `done_at = now()`, `open`으로 돌리면 비워요.

새 public 함수 없음 → 메타 테스트 함수 허용 목록은 그대로. 감사 대상에 `counsel_notes` 추가(미성년자 상담 내용).

### 2.3 내가 정한 것

- **학교 필드**: 이미 `student_private.school`(원장만 보는 테이블, 보안 S3)에 있어서 새로 만들지 않았어요. 학생 추가 화면에는 넣지 않고, 허브 헤더에서 비어 있으면 "학교 입력"으로 기본 정보 탭의 학교·보호자 카드로 보내요.
- **학생 메모(수업 일지)는 원장만** 봐요. 학생·학부모에게 보일지는 묻기 전까지 닫아 둬요.
- **테스트·클리닉은 학생 본인 읽기 정책까지** 만들었어요(그림 A의 메뉴). 학생 화면은 2단계.
- **클리닉 종류는 두 가지**(단어 재시험, 개념 보완). 원장 그림에 나온 그대로예요.
- **체크를 끄면 안 끝낸 클리닉만 지워요.** 실수로 체크했다 끈 경우를 위해서예요.
- **테스트 점수로 자동 클리닉은 하지 않아요.** 기준 점수를 원장에게 물어본 뒤 같은 트리거 방식으로 더해요.
- **상담 기록은 홈페이지 상담 신청과 따로** 둬요. 신청은 입학 전 학부모 문의(6개월 뒤 자동 삭제), 상담 기록은 재원생 기록(보존)이라 성격이 달라요.
- **삭제**: 테스트·상담·클리닉은 원장이 지울 수 있어요(잘못 쓴 것 정리). 수업 일지 메모는 내용을 비우고 체크를 끄면 돼요.
- **허브 탭 순서**는 그림 그대로: 기본 정보 · 출결 · 수업 일지 · 테스트 · 클리닉 · 상담 · 수납.

### 2.4 학생 화면 A (설계만, 2단계)

하단 탭 5개: **나의 수업**(홈+숙제 합침: 반 시간표·다음 수업·과제 제출) · **강의실**(내 반 영상 + 내 학교 내신 영상) · **자료실** · **기록**(테스트 기록 + 클리닉 두 칸) · **내 정보**. 질문은 영상 화면과 나의 수업 안 버튼으로 옮겨요.

- 테스트·클리닉 읽기는 이번 정책으로 바로 가능 → `features/test-records`, `features/clinic`에 학생용 목록만 더하면 돼요.
- 내신 강의실: `videos.school text null` 추가, 학생 정책에 "내 반 영상 또는 내 학교 영상" 조건. 학교는 `student_private`에 있어 `private.my_school()` 헬퍼가 필요해요.
- 자료실: 비공개 버킷 `materials` + `materials` 테이블(반·제목·파일 경로), 영상과 같은 정책 방식.

## 3. 원장에게 물어볼 것

1. 수업 일지의 **학생별 메모를 학생·학부모도 봐도 되나요?** (지금은 원장만)
2. **테스트 몇 점 미만이면 자동으로 재시험** 명단에 넣을까요? (예: 80% 미만) 단어·문법 기준이 다른가요?
3. 클리닉 종류가 "단어 재시험", "개념 보완" 말고 더 있나요? (예: 숙제 보충, 오답 노트)
4. 클리닉을 "끝냈어요"로 처리할 때 **재시험 점수도 같이 적고 싶나요?**
5. 상담 기록에 **다음 상담 예정일**이나 "학부모에게 공유" 같은 칸이 필요한가요?
6. 학생 화면 하단 탭이 5개뿐이라 **질문 탭을 빼고** 영상·수업 화면 안 버튼으로 옮겨도 될까요?
7. 내신 강의실 영상은 **학교별로 따로 찍나요, 반별 영상에 학교 꼬리표만 달면 되나요?**
8. 학습 자료실 파일 형식(PDF만? 한글·워드도?)과 한 파일 최대 크기.

## 4. 2단계 목록

- 학생 화면 A: 하단 탭 재구성, 나의 수업(시간표+과제), 기록(테스트·클리닉) 학생용 목록.
- 내신 강의실: 영상 학교 꼬리표 + 정책.
- 학습 자료실: 버킷·테이블·업로드·다운로드.
- 학부모 리포트: 링크 화면에 테스트·클리닉 요약(필요하면 수납).
- 테스트 점수 기준 자동 재시험(원장 답 2번 이후).
- 반 단위 테스트 일괄 입력(한 번에 반 전체 점수).
- 메뉴 용어 정리("결제" → "수납").

**학생 하단 탭**: 나의 수업 · 강의실 · 자료실 · 기록 · 질문 (5개가 최대라 강의실 = 수업 영상 + 내신 강의실, 기록 = 테스트 기록 + 클리닉으로 묶었어요. 숙제 전체 보기와 내 정보는 나의 수업 안에서 열어요.)

### 5.1 내가 정한 것 (2단계)

- **꼬리표 영상은 반이 달라도 그 학교 학생에게 보여요.** 원장 답 ⑦ 전까지의 방식. 학교 이름은 앞뒤 공백·대소문자만 무시하고 똑같아야 해요("양현고" ≠ "양현고등학교"). 퇴원생은 안 보여요. 꼬리표 영상도 업로드는 기존처럼 반을 골라 올려요.
- **학생 학교는 여전히 원장만 읽어요.** 학생 화면은 `private.my_school()`로 "내 학교 영상인지"만 판단하고 학교 이름 자체를 받지 않아요.
- **자료실 파일**: PDF, jpg·png, hwp·hwpx, doc·docx, 한 파일 20MB(원장 답 ⑧ 전 기본값). 브라우저가 한글 파일 형식을 모를 때가 많아 확장자로 형식을 정해 올려요. 내려받기 주소는 1분짜리이고, 반에서 빠지거나 퇴원하면 바로 못 받아요. 자료 수정은 없고 지운 뒤 다시 올려요.
- **통과 기준은 테스트마다** 적어요. 만점을 적으면 80%(올림)가 자동으로 채워지고 원장이 고치거나 비울 수 있어요(비우면 자동 재시험 없음). 단어 테스트 미달 → 단어 재시험, 문법 테스트 미달 → 개념 보완.
- **테스트를 지우면 안 끝낸 재시험도 지워요.** 끝낸 재시험은 기록으로 남아요.
- **학부모 화면**: 최근 4주 테스트와, 안 끝낸 클리닉 + 최근 4주 안에 끝낸 클리닉. 테스트·클리닉 메모는 원장용이라 보내지 않아요.
- **질문 탭은 그대로** 뒀어요(원장 답 ⑥ 전).
