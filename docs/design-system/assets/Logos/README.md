- `heesu-logo.svg` — 전체 로고(HS 마크 + 희수영어 + HEESU ENGLISH), 투명 배경, 여백 정리. 랜딩 첫 화면·인쇄물.

- `hs_beige.svg` / `hs_cream.svg` — HS 마크, 정사각 배경. 웹앱 아이콘(apple-touch-icon, manifest icon)으로 PNG 변환해 쓴다.
