> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sessions`·`attendance`·`homework_checks`·`points`(자동 포인트 트리거) + RLS + pgTAP, 학생용 `submit_homework` RPC, 디자인 시스템 `AttendanceTable`, 원장 화면 오늘·출결·숙제·수업일지·포인트, 학생 목록 포인트 열과 학생 상세 최근 기록을 로컬에서 끝까지 동작하게 만들고, v1 후속 항목 "class-ops"를 닫는다.

**Architecture:** 포인트는 DB만 계산한다: `attendance`·`homework_checks`의 `status`가 바뀌면 security definer 트리거 `private.sync_session_points()`가 그 수업·학생의 자동 행(1점)을 만들거나 지운다. 클라이언트는 수동 가감(`session_id` 없음)만 insert할 수 있다. 학생 쓰기는 `submit_homework(session_id)` 하나(submitted_at만). 프론트는 기능 폴더 `sessions`(수업일지·수업 시작)·`attendance`(출결 표·진행률·학생 기록)·`points`(순위·내역·가감)·`today`(오늘 화면 조립)로 나누고, 화면 → TanStack Query 훅 → data 함수 → Supabase(RLS)를 지킨다. 출결 칸은 낙관적 업데이트 + 칸별 직렬화(mutation `scope`) + 실패 시 그 칸만 되돌림.

  - 날짜는 브라우저 로컬 날짜 `yyyy-MM-dd`(`toLocalDateKey(new Date())`). DB `current_date`에 기대지 않는다.

## Review Focus

1. **원장이 같은 칸을 빠르게 여러 번 누르고, 그중 앞선 저장이 실패하는 경우**(느린 망) → 칸에는 마지막으로 누른 값이 남고 DB도 그 값이며, 되돌림은 그 뒤에 누른 게 없을 때만 일어나고 실패 토스트가 뜬다. → Task 5 `useSetCell` 테스트 "같은 칸 두 번 클릭, 첫 요청 실패 → 두 번째 값 유지, 요청 순서 1→2".
2. **출결·숙제를 이리저리 바꾸거나 학생이 "제출했어요"를 눌러도** → 자동 포인트는 수업당 정확히 0개 또는 1개이고 수동 가감 행은 그대로다. → Task 2 pgTAP "present→late→present → 1행", "숙제 먼저 done 후 출석 → 1행", "제출해도 중복 없음", "absent로 바꾸면 자동 행만 삭제".
3. **"수업 시작"·"오늘 수업 추가"를 두 번 누르거나 두 탭에서 동시에 누르는 경우** → 오류 없이 이미 있는 그 수업으로 간다. → Task 4 `startSession` 테스트 "23505 → 기존 id, created false", Task 6 TodayScreen "pending 중 두 번 클릭 → 1회".
4. **처음 누르는 칸(행 없음 → insert)과 이미 있는 칸(→ update)이 PostgREST upsert 한 가지 요청으로 둘 다 되는가** — 컬럼 단위 grant가 upsert의 `do update set <모든 payload 컬럼>`을 막으면 원장의 두 번째 클릭부터 전부 `42501`이 난다. → Task 1 pgTAP "PostgREST upsert 모양 그대로 insert·update 둘 다 lives_ok", Task 5 data 테스트가 payload 컬럼을 고정.
5. **주소의 `?class=`·`?id=`가 없거나 틀리거나 남의 것인 경우**(옛 북마크, uuid 아님, 지워진 반) → 무한 로딩 대신 첫 반으로 바꾸거나 "찾을 수 없어요" 카드. → Task 4 SessionFormScreen, Task 5 AttendanceScreen 테스트.
